### 근거 확인 꼬리말
id: bas-cite
meta: 모든 질문 끝에 붙이는 한 줄. 지어낸 답을 막는 가장 쉬운 방법
check: 답의 인용 번호를 하나 이상 눌러 원문과 맞는지 직접 보세요.
```
근거가 되는 부분을 인용해서 알려 주고, 소스에 없는 내용은 '소스에 없음'이라고 적어 줘.
```

### 문서 전체 구조 잡기
id: bas-structure
meta: 두꺼운 매뉴얼·지침을 넣자마자 던지는 첫 질문
check: '소스에 없음'으로 나온 칸은 담당자에게 따로 확인하세요.
```
[문서 이름]을 바탕으로 [대상]이 알아야 할 내용을 [영역/단계]별로 표로 정리해 줘.
열은 '[영역] | [해야 할 일] | [꼭 지킬 원칙] | [자주 하는 실수]'로 하고, 각 칸에 근거 인용을 달아 줘.
소스에 없는 내용은 '소스에 없음'이라고 적어 줘.
```

### 소스 끄고 켜며 비교하기
id: bas-toggle
meta: 소스 체크박스를 하나씩 끄고 같은 질문을 다시 해 봅니다. 켠 소스에 따라 답이 달라집니다
```
지금 켜져 있는 소스만으로 [질문]에 답해 줘. 어느 소스의 어느 부분을 근거로 했는지 소스 이름과 함께 밝혀 줘.
```

### 낱말 단위 존재 확인
id: bas-exist
meta: AI가 '있다/없다'고 말한 내용을 가장 확실하게 확인하는 질문
check: 이 질문의 답도 인용 번호를 눌러 원문 화면으로 확인하세요.
```
'[문서 이름]'에만 근거해서 답해 줘. '[낱말1]', '[낱말2]'라는 낱말이 나오는 부분을 각각 원문 그대로 인용해 줘. 없으면 '문서에 없음'이라고만 써 줘.
```

### 설명서 PDF 1개로 업무 체크리스트
id: ex-bas-jungip
kind: example
result: 항목마다 설명서 인용이 붙은 체크리스트 표가 나옴(기본정보 다시 가져오기 = 입력 자료 삭제, 보호자 휴대폰은 배정 문자에 사용, 마감 후 수정은 학년부장 마감취소 필요 등). 위장전입 확인 절차·우선배정 증빙서류처럼 설명서에 없는 항목은 '설명서에 내용 없음'으로 따로 표시함.
```
6학년 담임교사가 중학교 입학 배정 원서를 작성·마감할 때 놓치기 쉬운 확인 사항을 체크리스트 표로 정리해줘. 각 항목에 근거가 되는 설명서 부분을 인용해주고, 설명서에 없는 내용이면 없다고 말해줘.
```

### 근거 인용 질문
id: ex2-bas-cite
kind: example
result: '경찰·소방·간호 경력자'로 참여하는 경우 경력증명서가 자격 증빙으로 인정된다고 답하며 매뉴얼의 외부안전요원 자격 목록을 인용했다. 안전 연수 이수증(신규 14시간/재교육 7시간), 범죄전력 조회, 출발 당일 신분증 확인도 덧붙였고, 경력증명서 서식·최소 경력 기간 등은 '소스에 없음'으로 따로 표시했다.
```
외부 안전요원이 자격증 대신 경력증명서를 냈는데 인정되나요? 근거가 되는 부분을 인용해서 알려 주고, 소스에 없는 내용은 '소스에 없음'이라고 적어 줘.
```

### 소스 하나만 켜고 묻기
id: ex2-bas-toggle
kind: example
result: 체육특기자 요강 HWPX 하나만 켠 상태(입력창 '소스 1개')에서, 접수 기간 2026년 11월 4일(수)~11월 10일(화) 17:00, 제출처 북부교육지원청 중등교육지원과 생활교육팀이라고 답했다. 근거로 그 요강의 「Ⅵ. 원서 접수 및 결과 발표」「Ⅶ. 선발 일정」「Ⅷ. 제출 서류」를 소스 이름과 함께 밝혔다. 끝난 뒤 모든 소스를 다시 켰다.
```
지금 켜져 있는 소스만으로 체육특기자 입학 원서의 접수 기간과 제출처를 알려 줘. 어느 소스의 어느 부분을 근거로 했는지 소스 이름과 함께 밝혀 줘.
```

### 낱말 있는지 원문 확인
id: ex2-bas-exist
kind: example
result: '측우기'는 '문서에 없음'이라고만 답했고, '앙부일구'는 "해시계인 앙부일구와 자동 물시계인 자격루는 오늘날에도 잘 알려져 있다." 등 두 문장을 원문 그대로 인용했다. 끝에 다른 문서의 내용과 비교해 볼지 물었다.
```
'세종대왕.pdf'에만 근거해서 답해 줘. '측우기', '앙부일구'라는 낱말이 나오는 부분을 각각 원문 그대로 인용해 줘. 없으면 '문서에 없음'이라고만 써 줘.
```

### 실험 단계별 안전 표
id: ex2-bas-structure
kind: example
check: '소스에 없음' 표시는 하나도 없었음(모든 칸을 소스로 채웠다고 답함).
result: '6학년 과학실험 단계별 교사 지도 및 안전 가이드' 표로 실험 전(사전 실험, 5분 안전교육, 비상구·소화기·눈 세척기 점검, MSDS 비치), 실험 중(교사 임장, 냄새는 손으로 바람을 일으켜 맡기, 사고 시 즉시 중단), 정리(폐수·폐시약 이중 잠금 보관, 깨진 유리는 빗자루·쓰레받기)를 정리하고 '자주 하는 실수'를 칸마다 적었다.
```
이 노트북의 과학실험 안전 자료를 바탕으로 6학년 담임교사가 알아야 할 내용을 실험 단계(준비-실험 중-정리)별로 표로 정리해 줘.
열은 '단계 | 해야 할 일 | 꼭 지킬 원칙 | 자주 하는 실수'로 하고, 각 칸에 근거 인용을 달아 줘.
소스에 없는 내용은 '소스에 없음'이라고 적어 줘.
```
