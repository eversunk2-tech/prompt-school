### 근거 확인 꼬리말
id: bas-cite
meta: 모든 질문 끝에 붙이는 한 줄. 지어낸 답을 막는 가장 쉬운 방법
check: 답의 인용 번호를 하나 이상 눌러 원문과 맞는지 직접 보세요.
```
근거가 되는 부분을 인용해서 알려 주고, 소스에 없는 내용은 '소스에 없음'이라고 적어 줘.
```

### 문서 전체 구조 잡기
id: bas-structure
meta: 두꺼운 매뉴얼·지침을 넣자마자 던지는 첫 질문
check: '소스에 없음'으로 나온 칸은 담당자에게 따로 확인하세요.
```
[문서 이름]을 바탕으로 [대상]이 알아야 할 내용을 [영역/단계]별로 표로 정리해 줘.
열은 '[영역] | [해야 할 일] | [꼭 지킬 원칙] | [자주 하는 실수]'로 하고, 각 칸에 근거 인용을 달아 줘.
소스에 없는 내용은 '소스에 없음'이라고 적어 줘.
```

### 소스 끄고 켜며 비교하기
id: bas-toggle
meta: 실습①. 소스 체크박스를 하나씩 끄고 같은 질문을 다시 해 봅니다
```
지금 켜져 있는 소스만으로 [질문]에 답해 줘. 어느 소스의 어느 부분을 근거로 했는지 소스 이름과 함께 밝혀 줘.
```

### 낱말 단위 존재 확인
id: bas-exist
meta: AI가 '있다/없다'고 말한 내용을 가장 확실하게 확인하는 질문
check: 이 질문의 답도 인용 번호를 눌러 원문 화면으로 확인하세요.
```
'[문서 이름]'에만 근거해서 답해 줘. '[낱말1]', '[낱말2]'라는 낱말이 나오는 부분을 각각 원문 그대로 인용해 줘. 없으면 '문서에 없음'이라고만 써 줘.
```
