### [중입 프로젝트 ②] 담임용 업무 안내 문서(Word)

```
#역할: 동학년 담임을 챙기는 [학년] 부장
#명령: 동학년 담임에게 나눌 '[업무] 담임용 업무 안내' 문서를 만들어 줘.

```

### [중입 프로젝트 ②] 시스템 입력 항목에 맞춘 기초조사서(Word)
id: wk-jp-survey
meta: 조사서를 만들고, 입력에 빠진 항목이 없는지 확인하는 두 단계를 한 번에
check: 학생 이름·주민등록번호 같은 실제 개인정보는 노트북에 넣지 않습니다. 양식만 만듭니다.
```
#역할: [학년] 부장

#형식: 맨 아래에 [[시스템] 입력 항목 | 조사서 문항 | 근거] 대조표를 붙이고 Word(docx) 파일로 만들어 줘.
```

### 깐깐한 부장교사 점검
id: ex2-wk-bujang
kind: example
check: 답 첫머리가 '김 선생, 지난번에 점검해 준 인솔·안전요원 배치 외에…'로 시작해 같은 노트북의 이전 대화를 이어받는 말투가 나옴.
result: 4개 점검 항목별 표에서 계획안의 '여행사 답사 자료로 사전답사 대체', '비상 연락은 행정실·인솔 책임 교사 번호만', '우천 시에도 원안대로 진행' 등을 인용해 매뉴얼 기준(사전답사 필수, 先 유선 보고·後 사안 보고서, 실내 대체 프로그램 수립)과 비교하고 고친 문장을 제시했다. 끝에 전자 계약·특수조건, 사안 보고 체계·응급 연락망, 숙박 안전점검 서류·실내 대체 프로그램을 '결재 전에 꼭 고칠 3가지'로 적었다.
```
#역할: 너는 2026 부산시교육청 현장체험학습 운영 매뉴얼을 꿰고 있는 까다로운 20년 차 부장교사야.
#명령: 소스의 '수학여행_운영계획안_연수용'을 현장체험학습 운영 매뉴얼과 비교해서, 잘못되었거나 빠진 부분을 찾아 고쳐 줘.
#맥락
##점검 기준: 예산과 계약 절차, 숙박시설 안전점검, 비상 연락망과 응급 대처, 우천 시 대체 프로그램
##조건: 지적마다 계획안의 해당 부분과 매뉴얼 근거를 함께 인용해 줘. 매뉴얼에 근거가 없으면 '매뉴얼에 없음'이라고 표시해 줘.
##말투: 깐깐하게 지적하되, 고칠 방향은 친절하게.
#형식: 표(점검 항목 | 계획안 내용 | 매뉴얼 기준 | 문제점 | 고친 문장)로 정리하고, 마지막에 '결재 전에 꼭 고칠 3가지'를 번호로 적어 줘.
```

### 인수인계 월별 정리
id: ex2-wk-handover

check: '바뀐 점'이 작년 문서와 올해 문서의 비교라기보다 올해 문서끼리의 차이·유의사항으로 정리됨 — 노트북에 작년 문서가 따로 있는지 확인 필요.

```
#역할: 학부모 눈높이에 맞춰 쉽게 쓰는 초등학교 6학년 부장 #명령: 중학교 입학 배정 가정통신문 초안을 써 줘. #맥락: 일반배정·우선배정·재배정을 나눠 안내하고, 우리 학교 배정 중학교는 '!교육지원청 확인 결과'를 따라. 날짜는 소스에서 인용하고, 학생 이름 같은 개인정보 칸은 비워 둬. #형식: ① 본문(인사-배정 방법-일정-문의처) ② 뒷면: 우선배정 대상별로 학부모가 담임에게 낼 서류만 [대상 | 준비할 서류 | 내는 날짜] 표 ③ 학부모가 자주 물을 질문 3개와 답
```

### 중입 배정: 학부모 관점 점검 → Word
id: ex5-wk-jp-reader-check
kind: example
result: 서류 표의 서식 번호, '원본대조필', '8호 전학 조치', 국가유공자 증명서 제출처 표현, 학교가 출력해 주는 배정원서를 학부모 준비물처럼 쓴 곳, 비어 있는 발송일 등을 찾아 고친 문장을 표로 보여 주고, 반영본을 스튜디오에 docx(4쪽)로 저장했다.
```
이 가정통신문을 처음 받은 학부모 입장에서 다시 읽고 점검해 줘. ① 학부모가 모를 행정 용어(서식 번호, 원본대조필 등) ② 학부모가 아니라 학교가 내는 서류가 섞인 곳 ③ 날짜가 빠졌거나 소스와 다른 곳을 찾아 [위치 | 문제 | 고친 문장] 표로 보여 줘. 그다음 고친 내용을 모두 반영해서 가정통신문 전체를 Word(docx) 문서로 만들어 줘.
```
