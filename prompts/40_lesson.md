### 차시별 오개념 표
id: ls-misconc
meta: 단원 노트북의 첫 질문. [지도서]/[AI 제안]을 구분하게 하는 것이 핵심
check: [지도서]로 표시되었는데 인용 번호가 없는 줄은 원문으로 다시 확인하세요.
```
#역할: 너는 [학년] [교과]를 20년 가르친 수석교사야.
#명령: '[단원명]' 단원에서 학생들이 자주 갖는 오개념을 차시 순서대로 정리해 줘.
#맥락
##조건: 지도서에 나온 내용은 [지도서], 지도서에 없지만 네가 덧붙인 내용은 [AI 제안]으로 꼭 구분해 줘. [지도서] 항목에는 인용 번호를 달아 줘.
#형식: 표(차시 | 학생 오개념(학생 말투로) | 올바른 개념 | 교정 발문 또는 실험 | 출처 구분)
```

### 마인드맵 주제
id: ls-mindmap
meta: 스튜디오 → [마인드맵] 맞춤설정 '주제'에. 완성 후 노드를 누르면 채팅으로 이어집니다
```
단원 → 차시 → 핵심 개념 → 실험·관찰 활동 순서로 가지를 나눠 주고, 학생들이 헷갈리는 개념에는 '오개념 주의' 가지를 달아 줘.
```

### 퀴즈: 오개념을 오답 보기로
id: ls-quiz
meta: 스튜디오 → [퀴즈] 맞춤설정 '주제'에. 보기마다 해설이 나옵니다
check: 정답이 하나뿐인지, 학년 수준에 맞는지 몇 문항 직접 풀어 보세요.
```
[학년] 학생용 형성평가입니다. [차시 범위]([핵심 내용])를 물어 주세요. 오답 보기에는 학생들이 실제로 갖는 오개념(예: [오개념1], [오개념2])을 넣고, 해설에서 그 보기가 왜 틀렸는지 쉬운 말로 설명해 주세요.
```

### 슬라이드 1단계: 목차 먼저
id: ls-slide-outline
meta: 채팅에서. 답을 메모에 저장 → 소스로 변환 → 이름 '![차시] 슬라이드 목차'
```
#명령: [차시] '[학습 주제]' 40분 수업에 쓸 슬라이드 목차를 만들어 줘.
#맥락
##구성: 표지 1장 + 본문 6~8장 + 정리 퀴즈 1장
##조건: 장마다 '화면 제목 / 화면에 들어갈 글(2줄 이내) / 넣을 그림·사진 설명 / 교사 발문 1개'를 적어 줘. [학년]이 읽기 쉬운 짧은 문장으로.
#형식: 슬라이드 번호 순서의 목록
```

### 슬라이드 2단계: 목차 소스로 만들기
id: ls-slide-make
meta: 스튜디오 → [슬라이드 자료] 맞춤설정 → 발표자 슬라이드 → 설명란에. '슬라이드 개요 검토'를 켜세요
check: 그림 속 실험 기구·인물이 실제와 다른지 확인하고 [수정]으로 장별로 고치세요.
```
소스 '![차시] 슬라이드 목차'의 순서와 화면 글을 그대로 따라 만들고, 내용 확인은 지도서로 해 줘. [학년] 교실 TV용: 밝은 배경, 큰 글씨, 장마다 글은 2줄 이내, 실험 장면은 사진 느낌의 그림. 마지막 장은 OX 퀴즈 3문제.
```

### 슬라이드 수정 요청
id: ls-slide-fix
meta: 완성된 슬라이드 → [수정] → 고칠 장 선택 → 'N번 슬라이드 변경' 칸에. 여러 장을 모아 한 번에 생성
```
[고칠 부분, 예: 오른쪽 기기]를 [바꿀 모습, 예: 과학실용 '산소 측정기']로 바꿔 주고, [추가할 것, 예: 기기 아래에 '산소 측정기' 이름표]를 넣어 줘.
```

### 동영상 두 버전: 도입용
id: ls-video-intro
meta: [동영상 개요] → 설명 동영상(16:9) → 스타일 선택 → 맞춤 주제. '프로듀서 메모 검토'를 켜면 만들기 전에 장면을 고칠 수 있습니다
```
[학년] [교과] '[주제]' 도입용 3분 영상. [비교할 내용]을 비교하고, 끝에 학생에게 '[생각 질문]'을 물어 주세요. [학년]이 알아듣는 쉬운 말로.
```

### 동영상 두 버전: 배움이 느린 학생용
id: ls-video-short
meta: [동영상 개요] → 짧은 버전(9:16) → 맞춤 주제. 같은 단원을 다른 수준으로
```
배움이 느린 학생을 위한 1분 복습 영상. '[핵심 개념]'이 무엇인지 한 문장으로 먼저 설명하고, [사례 2개]만 골라 천천히 비교해 주세요. 어려운 말([피할 낱말])은 쓰지 마세요.
```

### 오디오 토론: 결론 없이 질문으로
id: ls-audio-debate
meta: [AI 오디오 오버뷰] → 형식 '토론' → 길이 '짧게'. 길이는 정확히 지켜지지 않습니다
```
[학년] 수업 도입용 토론. '[논쟁 질문]'을 두 호스트가 지도서의 사례를 근거로 논쟁하고, 마지막에 결론을 내지 말고 학생들에게 질문을 던져 주세요. 초등학생이 알아듣는 말로.
```

### 인포그래픽: 교실 게시용
id: ls-infographic
meta: [인포그래픽] → 방향 '세로' → 스타일(스케치 노트·귀여움 등) → 설명
check: 작은 글씨에 어색한 말이 없는지 크게 확대해서 확인하세요.
```
교실 게시용 세로 포스터. 제목 '[제목]'. [항목 수]칸으로 나눠 각 칸에 [넣을 내용]. 글자는 크고 적게, [학년] 수준.
```

### 대화형 보고서: 혼자 복습하는 학습 개요
id: ls-report
meta: [보고서] → 형식 '대화형' → 템플릿 '학습 개요' 연필 → 설명. [생성]은 한 번만 누르세요
```
[학년] [교과] '[단원명]'을 학생이 혼자 복습하는 학습 개요로 만들어 줘. 맨 앞에 핵심 질문 3개, 본문은 [핵심 내용]을 사례 중심의 짧은 문장으로, 중간중간 스스로 확인 퀴즈와 스튜디오 자료를 넣고, 마지막에 배운 내용을 한 문장으로 써 보는 칸을 넣어 줘.
```

### 슬라이드: 질문으로 시작하는 한 차시
id: ex-les-season-slide
kind: example
result: 질문으로 시작하는 표지·도입·자전축 비교 슬라이드가 만들어짐. [수정]으로 특정 장만 고치거나 PPTX로 내려받아 편집할 수 있음.
```
도입은 '여름이 더운 이유는 태양과 가까워서일까?' 질문으로 시작하고, 모형실험 방법과 결과 해석, 정리 퀴즈 순서로. 글자는 크고 적게, 밝고 친근한 그림 스타일로.
```
