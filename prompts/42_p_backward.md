### 맞춤 채팅 설정: 수업 노트북 기본 규칙
id: p2-setting
kind: example
meta: ⋮ → 채팅 설정 → [맞춤]. 업무용 설정에서 역할과 첫 규칙만 수업에 맞게 바꾼 글입니다
result: 성취기준 코드와 문장이 지도서 그대로 인용되고, 지도서에 없는 수행과제·채점기준 문장에는 ‘AI 제안:’이 붙어 나왔다.
```
#역할: 너는 초등학교 6학년 담임교사의 수업 준비를 돕는 동료 교사야.
#규칙
- 소스에 있는 내용으로 답하고, 성취기준과 차시 번호는 소스에 적힌 그대로 써 줘.
- 소스에서 찾지 못한 내용은 지어내지 말고 '소스에 없음'이라고 적어 줘.
- 소스에 없지만 네가 덧붙이는 의견이나 제안은 앞에 'AI 제안:'이라고 표시해 줘.
#형식: 결론을 먼저 한두 문장으로 말하고, 자세한 내용은 표나 번호 목록으로 정리해 줘.
```

```
우리 반 실태 (6학년 ○반 [  ]명, 이름 없이 숫자만 적음)

- [관련된 생활 경험] 이 있는 학생 [  ]명
- 긴 글 읽기를 어려워하는 학생 [  ]명, 한국어가 서툰 학생 [  ]명
- [좋아하는 활동]은 좋아하지만 [힘들어하는 활동]을 힘들어하는 학생이 많음
- [쓸 수 있는 기기와 써 본 도구]
- [지난 형성평가에서 약했던 부분과 정답률]
```

### 백워드 1단계: 바라는 결과
id: p2-ubd1
kind: example
meta: 채팅 창. [메모에 저장] → '!1 바라는 결과'
check: 성취기준 코드와 문장을 지도서와 대조
result: 성취기준 세 개([6사11-01]~[6사11-03])를 코드와 문장 그대로 옮기고, 영속적 이해와 본질적 질문은 “소스에 없음”이라고 밝힌 뒤 ‘AI 제안:’으로 두 개씩 제시. 첫머리에 우리 반 실태(용어가 낯선 11명, 그래프·표 읽기 58%)를 근거로 들었다.
```
#역할: 너는 백워드 설계(이해 중심 교육과정)에 밝은 초등학교 6학년 사회 수석교사야.
#명령: 이 단원의 '바라는 결과'를 정해 줘.
#맥락
##근거: 지도서를 근거로 하고, '우리 반 실태'를 참고해.
##조건: 단원 성취기준을 코드와 문장 모두 지도서에 적힌 그대로 옮겨 줘. 영속적 이해와 본질적 질문은 단원 성취기준을 모두 아우르게 해 줘.
#형식
① 단원 성취기준 ② 영속적 이해 2개 ③ 본질적 질문 2개(정답이 하나가 아닌 질문) ④ 표(성취기준 코드 | 학생이 알아야 할 것 | 할 수 있어야 할 것)
```

### 백워드 2단계: 수행과제와 채점기준
id: p2-ubd2
kind: example
meta: 채팅 창. '!1 바라는 결과'가 체크된 상태에서. [메모에 저장] → '!2 수행과제와 채점기준'
check: 채점기준 수준과 문장은 교사가 다듬어 확정
result: 수행과제 ‘똑똑한 소비자를 위한 우리 생활 속 물건 탐구 카드’(캔바 3쪽 카드뉴스, 쪽마다 성취기준 하나)를 GRASPS 표로 제시. 채점기준표에 우리 반의 약점(용어 이해, 그래프·표 읽기, 글 정리 부담)이 평가 요소로 들어갔다.
```
#명령: '!1 바라는 결과'에 도달했는지 확인할 단원 수행과제를 만들어 줘.
#맥락
##수행과제 하나로 단원 성취기준을 모두 평가하게 해 줘. 하나의 결과물 안에 성취기준이 각각 한 부분씩 들어가게.
##GRASPS(목표·역할·청중·상황·결과물·기준)로 설계하고, 학생이 실제 생활에서 겪을 만한 장면으로 해 줘.
##'우리 반 실태'에서 약한 점을 찾아 채점기준에 그 요소를 넣어 줘.
#형식
① GRASPS 표 ② 채점기준표(평가 요소 3개 × 잘함·보통·노력 필요, 요소마다 관련 성취기준 코드 표시, 학생이 이해할 쉬운 말) ③ 수준별 결과물 예시(각 2~3문장)
```

### 백워드 3단계: 차시 계획
id: p2-ubd3
kind: example
meta: 채팅 창. [메모에 저장] → '!3 차시 계획'
check: 차시 주제를 지도서 차시 목록과 대조
result: 20차시 표. ‘지도서 주제’ 칸은 지도서의 차시 주제 그대로, ‘수행과제 준비’와 ‘우리 반 조정’ 칸은 ‘AI 제안:’으로 채워졌다.
```
#명령: '!1 바라는 결과'와 '!2 수행과제와 채점기준'을 기준으로 이 단원 20차시의 학습 순서를 정리해 줘.
#맥락
##'지도서 주제' 칸에는 지도서에 적힌 차시 주제를 그대로 옮겨 줘.
##각 차시가 수행과제 결과물의 어느 부분을 준비하는지 '수행과제 준비' 칸에 적어 줘.
#형식: 표(차시 | 지도서 주제 | 이어지는 본질적 질문 | 수행과제 준비 | 형성평가 | 우리 반 조정)
```

### 꼼꼼한 동료 교사 검토
id: p2-peer
kind: example
meta: 채팅 창. '!1'~'!3'을 모두 체크하고 보냅니다
check: '바로 고칠 3가지'는 교사가 받아들일 것만 고르기
result: 점검 기준별 표와 ‘바로 고칠 3가지’：성취기준의 ‘기업의 자유’가 수행과제에서 빠짐, 학생이 그래프를 직접 찾게 한 점, 채점기준의 모호한 표현. 지적마다 소스 문장과 인용 번호가 붙었다.
```
#역할: 너는 백워드 설계 연수를 여러 번 진행한 꼼꼼한 동료 교사야.
#명령: '!1 바라는 결과', '!2 수행과제와 채점기준', '!3 차시 계획'을 함께 보고 고칠 점을 찾아 줘.
#맥락
##점검 기준: ① 바라는 결과–수행과제–차시가 서로 이어지는가 ② 채점기준이 학생이 이해할 말로 쓰였는가 ③ 시간이 현실적인가 ④ 우리 반 실태를 반영했는가
##조건: 지적마다 근거가 되는 소스 문장을 인용 번호와 함께 달아 줘.
#형식: 표(점검 기준 | 고칠 점 | 근거 | 고칠 방법), 마지막에 '바로 고칠 3가지'
```

```
##조건: 방금 찾은 '바로 고칠 3가지'를 반영하고, 고친 곳에는 (수정)이라고 표시해 줘. 성취기준과 차시 주제는 지도서에 적힌 그대로 둬.
#형식
1. 단원 개관(단원명, 성취기준, 우리 반 실태 요약)

3. 수행과제(GRASPS 표)와 채점기준표
4. 차시 계획 표
Word 파일로 만들어 줘.
```

### 틀: 백워드 3단계 차시 계획

```
#명령: '!1 바라는 결과'와 '!2 수행과제와 채점기준'을 기준으로 이 단원 [N]차시의 학습 순서를 정리해 줘.
#맥락
##'지도서 주제' 칸에는 지도서에 적힌 차시 주제를 그대로 옮겨 줘.
##각 차시가 수행과제 결과물의 어느 부분을 준비하는지 '수행과제 준비' 칸에 적어 줘.
```
