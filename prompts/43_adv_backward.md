### 맞춤 채팅 설정: 수업 노트북 기본 규칙
id: s3-setting
kind: example
meta: ⋮ → 채팅 설정 → [맞춤]. 업무용 설정에서 역할과 첫 규칙만 수업에 맞게 바꾼 글입니다
check: 지도서에 없는 내용은 'AI 제안:'으로 나옵니다. 수업에 쓸지는 교사가 정합니다.
result: 지도서 내용과 노트북의 제안이 한 답 안에서 구분되어 나옵니다.
```
#역할: 너는 초등학교 6학년 담임교사의 수업 준비를 돕는 동료 교사야.
#규칙
- 소스에 있는 내용으로 답하고, 성취기준과 차시 번호는 소스에 적힌 그대로 써 줘.
- 소스에서 찾지 못한 내용은 지어내지 말고 '소스에 없음'이라고 적어 줘.
- 소스에 없지만 네가 덧붙이는 의견이나 제안은 앞에 'AI 제안:'이라고 표시해 줘.
#형식: 결론을 먼저 한두 문장으로 말하고, 자세한 내용은 표나 번호 목록으로 정리해 줘.
```

### 질문 ①: 바라는 결과
id: s3-q1
kind: example
meta: 채팅 창. [메모에 저장] → '!1 바라는 결과'
check: 성취기준 코드는 인용 번호를 눌러 지도서 원문과 맞는지 확인하세요.
result: 주제별 성취기준과 '꼭 알아야 할 것 / 할 수 있어야 할 것' 표. 단원 핵심 질문은 지도서에 없어서 "소스에 없음이므로 AI 제안으로 구성"이라고 밝히고 2개를 제안합니다.
```
이 단원이 끝났을 때 학생이 꼭 알아야 할 것과 할 수 있어야 할 것을 성취기준과 함께 정리하고, 단원 핵심 질문 2개를 만들어 줘.
```

### 질문 ②: 수행과제와 채점 기준
id: s3-q2
kind: example
meta: 채팅 창. [메모에 저장] → '!2 수행과제와 채점 기준'
check: 수행과제는 대부분 'AI 제안'입니다. 우리 반 상황에 맞게 장면을 바꿔 달라고 다시 말하면 됩니다.
result: 지도서에 있는 평가 자료(상·중·하 예시, GRASPS 도구)를 먼저 정리하고, 그 위에 'AI 제안: 우리 반 체육대회 똑똑한 장바구니' 수행과제와 3단계 채점 기준표를 만듭니다.
```
그 결과를 확인할 수행과제 1개와 채점 기준표(잘함·보통·노력 요함)를 만들어 줘. 학생이 실제 생활에서 겪을 만한 장면으로 해 줘.
```

### 질문 ③: 차시 계획
id: s3-q3
kind: example
meta: 채팅 창. [메모에 저장] → '!3 차시 계획'
result: 1~20차시 표. '지도서 핵심 활동'과 '지도서 확인할 점' 열은 소스 내용, 'AI 제안: 수행과제 연계' 열은 노트북의 제안으로 나뉘어 나옵니다.
```
이 수행과제를 해낼 수 있도록 차시 계획을 표로 짜 줘. 지도서의 차시 순서를 따르고 차시마다 핵심 활동과 확인할 점을 적어 줘.
```
