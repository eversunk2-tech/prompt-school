### 복습 게임 웹페이지: 가계와 기업 탐정
id: p4-game
kind: example
meta: 제미나이 → [+] → 노트북 추가 → [+] → 도구 더보기 → Canvas → 붙여 넣기
check: 카드 내용을 지도서와 대조. 학생에게 주기 전에 끝까지 한 번 해 보기
result: 2분쯤 뒤 미리보기에 ‘가계와 기업 탐정’이 떴다. 1단계 카드 8장 분류(끌기 또는 누르면 바구니 선택 창) → 2단계 오개념 OX → 결과 확인. 카드 문장은 지도서에서 가져왔다.
```
#역할: 너는 초등 사회 수업용 웹앱을 만드는 개발자이자 6학년 사회 교사야.
#명령: 첨부한 노트북의 '시장경제와 국가 간 거래' 지도서 내용만 근거로, 학생이 혼자 하는 '가계와 기업 탐정' 웹페이지를 만들어 줘.
#맥락
##대상: 6학년, 태블릿 가로 화면
##구성: ① 하는 일 카드 8장을 '가계' 바구니와 '기업' 바구니로 옮기기 ② 오개념 OX 퀴즈 6문제 ③ 틀린 문제는 지도서의 사례로 설명
##조건: 지도서에 없는 내용은 넣지 말 것. 큰 글씨, 밝은 색, 효과음 없이. 점수와 '다시 하기' 버튼. 카드는 터치·마우스 모두 끌 수 있고(Pointer Events), 끌기가 어려운 학생을 위해 한 번 누르면 옮겨지게.
#형식: 단일 HTML 파일(Canvas에서 바로 실행)
```

### 소크라테스식 학습 튜터 웹앱
id: p4-socratic
kind: example
meta: 제미나이 Canvas. 노트북을 붙이고 보냅니다
check: 일부러 틀린 답을 넣어 정답을 말하지 않는지 확인
result: 튜터 소개와 예시 질문 세 개로 시작. 질문에는 ‘힌트 질문’으로 답하고, 틀린 답에는 다른 힌트를, 주제와 관계없는 말에는 붉은 글씨 경고를 보여 주었다.
```
#역할: 너는 사회 교육 전문가인 초등 수석교사이자 앱 개발자야.
#명령: 6학년 학생들의 사회 학습을 위한 학습 튜터 웹앱을 만들어 줘.
#맥락
##조건
- 주제: 3~4차시-가계와 기업의 역할을 알아볼까요
- 학생의 질문에 답을 바로 알려 주지 말고, 힌트 질문을 계속 제시하며 스스로 답을 찾게 함(소크라테스식). 두 번 틀려도 정답 용어는 말하지 않음.
- 처음 시작할 때 튜터 소개와 함께 예시 질문 2~3개를 보여 줌.
##제한사항
- 첨부한 노트북의 내용만 근거로 답하고, 6학년 교과 수준을 벗어나지 말 것.
- 6학년 수준 어휘로 3~4문장 이내.
- 선정적·폭력적이거나 주제와 관계없는 대화에는 "그러한 대화는 할 수 없습니다. 학습에 집중하세요."를 붉은색으로 표시.
#형식: 단일 HTML(css, js 포함), 입력창은 화면 아래
```
