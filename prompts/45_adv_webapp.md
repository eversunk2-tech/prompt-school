### 복습 퀴즈 웹앱 만들기
id: s5-app
kind: example
meta: 제미나이 입력창 [+] → 도구 더보기 → Canvas, 다시 [+] → Notebooks → 노트북 선택 → [추가]
check: 웹앱의 문제와 정답을 노트북의 ‘!마무리 퀴즈’ 소스와 한 번 맞춰 봅니다.
result: 1분 30초쯤 뒤 미리보기에 웹앱이 뜹니다. ‘!마무리 퀴즈’의 5차시 세 문제(○×, 객관식, 핵심 정리)가 그대로 들어가고, 틀리면 ‘다시 생각해 볼까요? (힌트)’가 나오며, 끝나면 점수와 ‘5차시 꼭 기억해요!’ 정리가 보입니다.
```
'!마무리 퀴즈'에 있는 5차시 문제로 6학년 학생용 복습 퀴즈 웹앱을 만들어 줘. 한 문제씩 풀고, 틀리면 힌트를 보여 주고, 마지막에 점수를 알려 줘.
```

### 웹앱 고치기
id: s5-fix
kind: example
meta: Canvas 화면 오른쪽 아래 [Gemini에게 물어보기]. 바꾸고 싶은 점을 말로 적습니다
check: 고친 뒤 미리보기가 비어 보이면 “미리보기 화면이 비어 있어. 고쳐 줘.”라고 한 줄 더 보냅니다.
result: 글자가 커지고, 결과 화면에 ‘틀렸던 문제만 다시 풀기 (1문제)’ 버튼이 생깁니다.
```
글자를 더 크게 하고, 마지막 화면에 틀렸던 문제만 다시 푸는 버튼을 넣어 줘.
```

### 틀: 노트북 소스로 웹앱 만들기
id: s5-tpl
meta: [  ] 안만 바꿔 씁니다. 소스 이름은 노트북에 보이는 그대로 적습니다
```
'[소스 이름]'에 있는 [몇 차시 / 어떤 내용](으)로 [학년] 학생용 [복습 퀴즈 / 낱말 카드 / 순서 맞추기] 웹앱을 만들어 줘. [한 문제씩 풀고, 틀리면 힌트를 보여 주고, 마지막에 점수를 알려 줘.]
```
