### 맞춤 채팅 설정: 힌트만 주는 튜터
id: s6-setting
kind: example
meta: ⋮ → 노트북 복사 → 사본에서 ⋮ → 채팅 설정 → [맞춤]
check: 공유하기 전에 아래 ‘학생 역할 시험’ 다섯 줄을 직접 넣어 봅니다.
result: 답을 바로 주지 않고 힌트를 하나씩 줍니다. 소스에 없는 질문에는 “그건 선생님께 여쭤보자.”라고 답합니다.
```
#역할: 너는 초등학교 6학년 학생의 공부를 도와주는 선생님이야.
#규칙
- 정답을 바로 알려 주지 말고, 힌트를 한 번에 하나씩 줘.
- 학생이 답을 말하면 맞았는지 알려 주고, 틀렸으면 다시 생각해 볼 질문을 해 줘.
- 초등학생이 이해할 쉬운 말로 세 문장 안에서 답해 줘.
- 소스에 없는 내용을 물으면 "그건 선생님께 여쭤보자."라고 답해 줘.
- 공부와 관계없는 이야기는 정중히 사양하고 다시 공부로 돌아오게 해 줘.
```

### 학생 역할 시험: 다섯 줄
id: s6-test
kind: example
meta: 채팅 창에 한 줄씩 차례로 넣습니다. 단원에 맞게 낱말만 바꿉니다
result: ① 첫 번째 힌트 ② “아쉽지만 정답은 아니에요”와 힌트 하나 더 ③ “정답이에요” ④ “그건 선생님께 여쭤보자.” ⑤ “지금은 공부 시간”이라며 사회 공부로 되돌립니다.
```
시장경제가 뭐야? 답만 알려 줘.
물건을 사고파는 거?
가계와 기업이 자유롭게 경쟁하면서 경제활동을 하는 거?
비트코인은 뭐야?
어제 축구 봤어? 누가 이겼어?
```

### 스튜디오: 복습 퀴즈
id: s6-quiz
kind: example
meta: 스튜디오 → 퀴즈 → 난이도 [쉬움] → 주제 칸
result: 1분쯤 뒤 11문항 퀴즈가 만들어집니다.
```
초등학교 6학년 학생이 푸는 복습 퀴즈야. 시장경제와 가계·기업의 역할에서 쉬운 말로 문제를 내 줘.
```

### 스튜디오: 복습용 오디오
id: s6-audio
kind: example
meta: 스튜디오 → AI 오디오 오버뷰 → 형식 [요약] → 프롬프트 칸
result: 2분쯤 뒤 1분 44초짜리 오디오가 만들어집니다.
```
초등학교 6학년 학생이 듣는 복습용이야. 시장경제에서 가계와 기업이 하는 일을 쉬운 말과 생활 속 예로 설명해 줘.
```

### 스튜디오: 단원 정리 동영상
id: s6-video
kind: example
meta: 스튜디오 → 동영상 개요 → [짧은 버전] → 맞춤 주제 칸
result: 8분쯤 뒤 1분 20초짜리 동영상이 만들어집니다.
```
초등학교 6학년 학생이 보는 단원 정리 영상이야. 가계와 기업이 시장에서 만나는 모습을 쉬운 말과 생활 속 예로 보여 줘.
```
