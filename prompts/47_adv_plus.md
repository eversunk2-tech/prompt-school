### 틀: 우리 반 실태 한 장
id: s7-class
meta: [+ 소스] → 복사된 텍스트. 이름 없이 숫자만 적어 소스로 넣습니다. 소스 이름은 ‘우리 반 실태’로
check: 학생 이름이나 번호처럼 누구인지 알 수 있는 내용은 적지 않습니다.
```
우리 반 실태 (6학년 ○반 [  ]명, 이름 없이 숫자만 적음)
- [이 단원 개념을 어떻게 알고 있는지] 학생 [  ]명
- [낯설어하는 낱말] 을 처음 듣는다고 답한 학생 [  ]명
- [관련된 생활 경험] 이 있는 학생 [  ]명
- 긴 글 읽기를 어려워하는 학생 [  ]명, 한국어가 서툰 학생 [  ]명
- [좋아하는 활동]은 좋아하지만 [힘들어하는 활동]을 힘들어하는 학생이 많음
- [쓸 수 있는 기기와 써 본 도구]
- [지난 형성평가에서 약했던 부분과 정답률]
```

### 우리 반 실태를 넣고 묻기
id: s7-class-q
kind: example
meta: 채팅 창. ‘우리 반 실태’ 소스 체크를 끄고 한 번, 켜고 한 번 보내면 차이가 보입니다
result: 지도서만 체크하면 일반적인 어려움과 함께 “우리 반 실태에 맞춘 세부 난점은 소스에 없음”이라고 답합니다. 실태를 체크하면 “‘시장=장소’로만 아는 15명, 낱말이 낯선 11명”처럼 우리 반 숫자로 답하고, 온라인 쇼핑 경험 17명을 디딤돌로 쓰는 지도 방법을 ‘AI 제안’으로 붙입니다.
```
2차시 수업에서 학생들이 어려워할 내용과 지도 방법을 알려 줘.
```

### 꼼꼼한 동료 교사 검토
id: s7-review
kind: example
meta: 채팅 창. ‘!1 바라는 결과’, ‘!2 수행과제와 채점 기준’, ‘!3 차시 계획’과 ‘우리 반 실태’가 체크된 상태
check: 고칠 방법은 ‘AI 제안’입니다. 받아들일 것만 골라 “이 내용을 반영해서 !2를 고쳐 줘.”라고 이어서 말합니다.
result: ‘약한 곳 / 어긋남(소스 근거) / AI 제안: 고칠 방법’ 표. 글쓰기 위주 수행과제가 글 정리를 힘들어하는 학급 실태와 맞지 않는다는 점, 표·그래프 읽기 지도가 빠진 점, 마지막 두 차시에 활동이 몰린 점을 짚습니다.
```
지금까지 만든 단원 설계(!1, !2, !3)를 꼼꼼한 동료 교사 입장에서 검토해서, 약한 곳 세 가지와 고칠 방법을 알려 줘.
```

result: 보충·기본·심화 활동지 3종과 공통 채점 기준표가 든 10쪽 Word 파일. 보충형에는 쉬운 낱말 풀이와 문장 틀이, 심화형에는 비교표와 평가표가 들어갑니다.
```
수행과제에 맞춰 기본·보충·심화 세 수준의 활동지를 만들어 줘. 우리 반 실태를 반영하고, Word 파일로 만들어 줘.
```
