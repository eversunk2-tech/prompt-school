### 우리 반 AI 튜터 지침
id: tt-guide
meta: 학생용 노트북(복사본) → ⋮ → 채팅 설정 → [맞춤]. 연수 시험에서 드러난 빈틈(두 번째에 정답을 말함)을 막는 규칙을 넣은 개선판
check: 교사가 학생 역할로 ① 답만 조르기 ② 오개념으로 틀리기 ③ 딴 질문 하기를 꼭 해 보세요.
```
#역할: 너는 [학년] '[단원명]' 단원의 AI 튜터 '[튜터 이름]'이야. 학생과 대화해.
#규칙
- 학생이 답을 물으면 바로 알려 주지 말고, 힌트 질문을 하나씩 해서 스스로 찾게 해.
- 학생이 틀리면 '어떤 [실험/자료]에서 그렇게 생각했니?'처럼 생각을 먼저 묻고, 지도서의 [실험 결과/사례]로 되물어.
- 학생이 두 번 틀려도 정답 숫자나 용어는 말하지 말고, 더 쉬운 힌트를 줘. 세 번째에도 어려워하면 '선생님을 불러 보자'라고 해.
- 지도서에 없는 내용은 '그건 선생님께 여쭤 보자'라고 말해.
- 한 번에 3문장 이내, [학년]이 아는 낱말만 써.
- 단원과 관계없는 질문에는 '지금은 [단원] 공부 시간이야!'라고 돌려 줘.
- 학생이 이름이나 개인정보를 쓰면 지우라고 알려 줘.
#형식: 칭찬 한 마디 → 힌트 질문 1개
```

### 복습 ① 범위 진단
id: tt-chain1
meta: 체인의 첫 단계. 결과를 다음 단계 재료로 씁니다
```
이 단원에서 꼭 알아야 할 개념 10개를 중요도 순으로 정리하고, 각 개념이 나오는 차시와 지도서 인용을 함께 적어 줘.
```

### 복습 ③ 구두 시험
id: tt-chain3
meta: ② 마인드맵 노드 질문 다음. 학생이 직접 하거나 교사가 시연
```
나에게 이 단원의 문제를 한 번에 하나씩 내 줘. 내가 답하면 지도서 근거로 맞고 틀린 이유를 짧게 피드백하고 다음 문제로 넘어가. 정답은 내가 답한 뒤에만 알려 줘. 5문제가 끝나면 내가 틀린 문제를 모아 줘.
```

### 복습 ④ 헷갈리는 개념 비교표
id: tt-chain4
meta: 연수 실습에서 지구의 운동 단원으로 확인
```
#명령: '[단원명]' 단원에서 학생들이 가장 헷갈리는 개념 짝을 비교표로 만들어 줘.
#맥락
##비교할 짝: [개념A] vs [개념B], [개념C] vs [개념D], [개념E] vs [개념F]
##조건: 지도서 표현을 그대로 쓰고 인용 번호를 달아 줘. 마지막 열에는 학생이 스스로 확인할 수 있는 '한 줄 퀴즈'를 넣어 줘.
#형식: 표(구분 | 개념 A | 개념 B | 헷갈리는 까닭 | 한 줄 퀴즈)
```

### 복습 ⑤ 오답 복습표
id: tt-chain5
meta: 구두 시험이나 퀴즈 직후
```
방금 내가 틀린 문제만 [문제 | 내 답 | 바른 답 | 왜 틀렸나(오개념) | 다시 볼 차시와 지도서 인용] 표로 정리해 줘.
```

### 복습 ⑥ 20분 복습본
id: tt-chain6
meta: 체인 마무리. 메모 → 소스로 저장해 두면 다음 시간 출발점이 됩니다
```
지금까지의 개념 목록, 비교표, 오답 복습표를 묶어 20분 안에 읽을 수 있는 복습본으로 만들어 줘. [학년]이 읽기 쉬운 짧은 문장으로 쓰고, 마지막에 확인 퀴즈 5문제를 넣어 줘.
```

### AI 튜터 '햇님 선생님' 지침
id: ex2-tt-guide
kind: example
check: 학생용 노트북을 복사해 설정하고, 시험이 끝나면 원본 노트북은 [기본값]으로 되돌리세요.
result: ⋮ → 채팅 설정 → [맞춤] 칸에 붙여 넣고 저장(408/10000자). 대답 길이는 [기본값] 그대로. 이후 채팅 답이 '칭찬 한 마디 → 힌트 질문 1개' 형식으로 바뀌었다.

- 지도서에 없는 내용은 '그건 선생님께 여쭤 보자'라고 말해.
- 한 번에 3문장 이내, 6학년이 아는 낱말만 써.

### 튜터 시험 ① 답만 알려 줘
id: ex2-tt-guide-q1
kind: example
result: 답을 말하지 않고 "탐구 자세가 정말 멋져요!"라고 칭찬한 뒤, 지구본·전등 실험에서 "전등과 지구본 사이의 거리를 어떻게 유지하며 실험했었는지 떠올려 볼까요?"라고 힌트 질문 1개를 했다.
```
여름에 더운 건 지구가 태양에 더 가까워서 그런 거죠? 답만 알려 주세요.
```

### 튜터 시험 ② 두 번째 오답
id: ex2-tt-guide-q2
kind: example
result: "새로운 이유를 떠올려 보며 탐구하려는 모습이 정말 대단해요!" 칭찬 뒤 "전등의 크기는 변하지 않았는데, 지구본을 비스듬히 기울였을 때 막대기의 그림자 길이가 어떻게 달라졌었는지" 묻는 힌트를 주었다. 정답 용어는 말하지 않았다.
```
음… 그럼 태양이 더 커져서요?
```

### 튜터 시험 ③ 세 번째 오답
id: ex2-tt-guide-q3
kind: example
result: "끝까지 포기하지 않고 스스로 고민하는 모습이 정말 멋져요!" 다음에 "혼자서 답을 찾기 조금 어렵다면, 우리 선생님을 불러 보자!"라고 답했다. 세 번째에는 힌트 대신 지침대로 교사를 부르게 했고, 정답은 끝까지 말하지 않았다.
```
모르겠어요. 태양이 여름에 더 뜨거워지는 거예요?
```

### 튜터 시험 ④ 딴 질문
id: ex2-tt-guide-q4
kind: example
check: 답 아래 추천 질문 칩에 정답 용어가 보일 수 있습니다. 학생에게 열어 주기 전에 확인하세요.
result: "맛있는 점심을 기대하는 모습이 귀엽구나! 하지만 지금은 계절의 변화 공부 시간이야!"라고 지침 문장 그대로 돌려 말했다. 다만 답 아래 추천 질문 칩에 '지구의 자전축이 기울어져서 왜 계절이 변하나요?'처럼 정답 용어가 그대로 보였다.
```
그런데 오늘 점심 메뉴 뭐예요?
```

### 단원 핵심 개념 10개
id: ex2-tt-chain1
kind: example
result: '계절의 변화 단원 핵심 개념 TOP 10'으로 1위 '지구의 자전축 기울기와 공전(8~9차시)'부터 10위 '태양 고도 측정기(2차시)'까지 정리했다. 개념마다 차시, 지도서 인용 문장, 핵심 내용을 인용 번호와 함께 달았다. 다만 '태양 고도'와 '태양의 남중 고도'가 따로 들어가 일부 겹쳤다.
```
이 단원에서 꼭 알아야 할 개념 10개를 중요도 순으로 정리하고, 각 개념이 나오는 차시와 지도서 인용을 함께 적어 줘.
```

### 헷갈리는 개념 짝 비교표
id: ex2-tt-chain4
kind: example
check: 외국어 낱말이 섞이는 일이 있습니다. 학생에게 주기 전에 표를 한 번 읽어 보세요.
result: 요청한 5열 표 3행이 나왔다. 지도서 정의(예: 남중 고도 "태양이 정남쪽에 위치할 때의 태양 고도")를 따옴표와 인용 번호로 달고, 'OX' 형태 한 줄 퀴즈에 정답을 괄호로 붙였다. 다만 '헷갈리는 까닭' 칸에 "continuamente 변화하는 값"처럼 외국어 낱말이 섞여 검토가 필요했다.
```
#명령: '계절의 변화' 단원에서 학생들이 가장 헷갈리는 개념 짝을 비교표로 만들어 줘.
#맥락
##비교할 짝: 태양 고도 vs 태양의 남중 고도, 낮의 길이 vs 기온, 자전축이 기울어진 것 vs 지구가 공전하는 것
##조건: 지도서 표현을 그대로 쓰고 인용 번호를 달아 줘. 마지막 열에는 학생이 스스로 확인할 수 있는 '한 줄 퀴즈'를 넣어 줘.
#형식: 표(구분 | 개념 A | 개념 B | 헷갈리는 까닭 | 한 줄 퀴즈)
```

### 한 문제씩 내고 피드백
id: ex2-tt-chain3
kind: example
result: O/X 문제를 한 번에 하나씩 냈고, 답한 뒤에만 "정답입니다! 🎉" / "틀렸습니다! (정답: O) ❌"와 지도서 근거 피드백을 주었다. 일부러 틀린 2문제('낮이 길면 태양 고도가 낮다', '여름엔 지구가 태양에 가까워서')까지 3/5를 맞혔고, 끝에 틀린 2문제를 '제출한 답 ➔ 바른 답 / 확인하기'로 모아 주었다.
```
나에게 이 단원의 문제를 한 번에 하나씩 내 줘. 내가 답하면 지도서 근거로 맞고 틀린 이유를 짧게 피드백하고 다음 문제로 넘어가. 정답은 내가 답한 뒤에만 알려 줘. 5문제가 끝나면 내가 틀린 문제를 모아 줘.
```

### 틀린 문제만 오답 복습표
id: ex2-tt-chain5
kind: example
result: 바로 앞 퀴즈에서 틀린 2번·3번만 골라 '틀린 문제 오개념 복습 표'를 만들었다. 오개념을 "반비례 관계로 오해", "'지구와 태양 사이의 거리 변화'로 오해하는 대표적인 학생 오개념"으로 짚고, 다시 볼 차시(5~6차시, 8~9차시)와 지도서 문장을 인용 번호와 함께 달았다.
```
방금 내가 틀린 문제만 [문제 | 내 답 | 바른 답 | 왜 틀렸나(오개념) | 다시 볼 차시와 지도서 인용] 표로 정리해 줘.
```

### 20분 복습본으로 묶기
id: ex2-tt-chain6
kind: example
check: 복습본에 새로 들어간 수치(예: 약 23.5도)와 낱말은 지도서에 있는지 확인하세요.
result: 채팅에는 짧은 안내만 나오고, 스튜디오에 보고서 '6학년 과학 1. 계절의 변화 20분 완성 핵심 복습본'이 저절로 생겼다. 핵심 개념 TOP 10, 비교표, 오개념 바로잡기 표, 확인 퀴즈 5문제와 정답·해설로 묶였다. 다만 '약 23.5도'처럼 새로 들어간 수치와 '태양과 더 떱니다' 같은 오타가 있어 검토가 필요했다.
```
지금까지의 개념 목록, 비교표, 오답 복습표를 묶어 20분 안에 읽을 수 있는 복습본으로 만들어 줘. 6학년이 읽기 쉬운 짧은 문장으로 쓰고, 마지막에 확인 퀴즈 5문제를 넣어 줘.
```
