### 수업지도안 설계 (개선판, 3턴)
id: gp-plan
meta: 원래 9턴이던 순차 질문 방식을 '미리 답함 + 0단계 보고 + 자기 점검표'로 줄인 판. 연수에서 프롬프트 → 소스 확인 → '진행' 3번으로 지도안·평가·학습지 완성
check: 성취기준 코드와 문장, 시간 합계, 지도서와 다른 부분을 꼭 원문과 대조하세요.
```
#역할: 너는 [학년] [교과] 수업을 나와 함께 설계하는 수석교사야.
#명령: 첨부한 노트북을 근거로 '[단원명]' 단원 [N차시] 40분 수업지도안(세안)을 만들어 줘.
#맥락
##자료 우선순위: ① 지도서 원본 ② '!'로 시작하는 설계 카드(감사·재검증을 마친 메모). 둘이 다르면 지도서를 따르고, 그 부분에 [확인 필요]를 붙여 알려 줘.
##우리 반: [인원]명, [모둠 구성], [기기 환경], [학생 특성(익명으로)]
##수업 방향(미리 답함): 수업 모형은 [모형 또는 '네가 추천하고 이유를 한 줄로'], 활동은 [활동 형태], 에듀테크는 [도구], AI 튜터는 [사용/사용 안 함].
##조건: 단계마다 교사 발문과 예상 답변 2개 이상, 시간 합계 40분, 성취기준은 지도서 문장 그대로 인용, [학년]이 이해할 쉬운 용어.
#형식
0단계(지금): 네가 읽을 수 있는 소스 이름을 모두 나열하고, [확인 필요] 항목만 짧게 보고한 뒤 "지도안을 만들까요?"라고 물어 줘.
1단계(내가 '진행'이라고 하면): Canvas 문서로 ① 수업 개요 표(과목·단원·차시·수업 모형·성취기준·학습 목표·에듀테크 활용 계획·수업 의도·자료) ② 본시 지도안 표(단계 | 시간 | 교수·학습 활동(발문·예상 답변) | 자료 및 유의점) ③ 평가 기준표(상·중·하, '~함.'으로 끝나게) ④ 학생 학습지(A4 1쪽: 핵심 정리, 내가 만든 질문, 탐구 결과 칸). 마지막에 자기 점검표(시간 합계, 성취기준-활동-평가 연결, 지도서와 다른 부분)를 붙여 줘.
```

### 소스 확인 질문
id: gp-sources
meta: 제미나이는 노트북을 통째로 읽지 않고 필요한 부분을 가져옵니다. 0단계 보고가 이상하면 바로 이 질문
```
첨부한 노트북에 들어 있는 소스 이름을 모두 나열해 줘. 그리고 '[설계 카드 이름]'의 [항목]과 지도서의 해당 내용이 서로 일치하는지 원문을 인용해 비교해 줘.
```

### 루브릭(평가 기준표)
id: gp-rubric
meta: 지도안이 나온 뒤 이어서. 2026 프롬프트 연수 원본을 그대로 살린 프롬프트
```
#역할: 너는 교육과정–수업–평가 일체화를 구현하는 과정 중심 평가 전문가야.
#명령: 앞서 작성한 수업지도안을 바탕으로, 학생들이 도달해야 할 성취 수준을 평가하기 위한 루브릭을 작성해 줘.
#맥락
##'지식·이해 / 과정·기능 / 태도·참여'가 골고루 반영되도록 3~4개의 평가 요소 추출
##상·중·하의 구분이 명확해야 함(예: '상'은 정확히 해결함, '중'은 해결함, '하'는 도움을 받아 해결함)
##문장은 '~함.'으로 끝나도록 작성
#형식: 표 형태로, 각 등급별(상·중·하) 구체적 행동 특성을 세부 서술
```

### 가정통신문
id: gp-letter
meta: 가장 쉬운 첫 연계 실습. 학교 양식에 붙여 날짜·연락처만 고칩니다
```
첨부한 노트북의 '[단원명]' 단원 내용을 바탕으로, 이번 주 [학년] [교과] 수업에서 배우는 내용과 가정에서 아이와 함께 해 볼 수 있는 [활동] 1가지를 학부모 안내문으로 써 줘. 학부모가 읽기 쉬운 말로 A4 반쪽 이내, 지도서 내용을 근거로 하고 과장하지 말 것.
```

### 대체 수업 아이디어
id: gp-alt
meta: 지도서 기본 흐름 대신 새 활동이 필요할 때
```
첨부한 노트북의 [N차시] 성취기준을 그대로 지키면서, 지도서 기본 활동을 대신할 수업 활동 3가지를 제안해 줘. 각 활동마다 [활동 이름 | 진행 절차 | 준비물 | 성취기준과 연결되는 지점 | 예상되는 어려움]을 표로 쓰고, 지도서에 근거가 있는 부분은 근거를 밝혀 줘.
```
