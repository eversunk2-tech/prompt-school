### 소크라테스식 학습 튜터 웹앱 (국회)
id: ex-cv-socratic
kind: example
```
#역할: 너는 많은 연구 경험을 가진 사회학자인 초등수석교사이며 앱 개발 전문가야.
#명령: 초등학교 6학년 학생들의 사회학습을 위한 학습 튜터 프로그램을 만들어줘.
#맥락
##조건 :
-주제: 9차시-국회는 무슨 일을 할까요?
-튜터의 문체: 부드럽고 친절한 문체
-학생의 질문에 단순히 답을 알려주는 것이 아니라 힌트 질문을 계속적으로 제시하며 학생이 스스로 답을 찾아내도록 함(소크라테스식 튜터)
-처음 대화를 시작할 때 학생에게 튜터를 소개하는 간단한 인사말과 함께 궁금한 것을 질문하라고 함. 예시 질문을 함께 제시하여 학생의 사고 활성화를 도움.
##제한사항
-첨부한 노트북lm 의 내용을 바탕으로 대답함
-노트북lm에 분석된 6학년 사회 교과내용 수준을 벗어나지 말 것
-초등학교 6학년 수준에 맞는 어휘를 사용하고 3~4문장 이내로 간결하게 말할것
-학생이 선정적, 폭력적이거나 학습 주제와 관련없는 대화를 할 경우, "그러한 대화는 할 수 없습니다. 학습에 집중하세요" 하는 문구를 붉은 색으로 나타내어 경고하기
-학생의 단순 질문에 절대로 정답을 바로 알려주지 말것. 예를 들면, "국회가 뭐하는 곳이야?"라고 물었을 경우 "법을 만드는 곳"이라는 답이 바로 나오면 안 됨.
```

### 역사 토론 챗봇 웹앱 (정도전 vs 정몽주)
id: ex-cv-debate
kind: example
```
#역할: 너는 역사학자이며 숙련된 초등사회교육 전문가인 수석교사이며 앱 개발 전문가야.
#명령: 초등학교 5학년 학생들의 사회학습을 위한 토론 프로그램을 만들어줘. 주제는 조선의 개국과 관련한 찬반 논쟁이야.
#맥락
##토론 형태 : 정몽주와 정도전 중 한명의 입장을 학생이 선택하면 그 반대편의 인물과 가상의 토론을 채팅으로 함
##조건 :
-역사적 사실을 바탕으로 두 인물의 입장을 구체적이고 상세하게 말할 수 있는 채팅봇이 만들어져야 함
-네이버 지식백과 등의 웹 검색을 통해 정몽주, 정도전, 조선 건국에 대한 문서의 내용을 충분히 학습할 것
-대화 문장의 수준은 초등학교 5학년 학생이 이해하기 쉬워야 하며 3~4문장 이내로 말할 것
-채팅 종료 후 처음으로 돌아가면 토론을 새롭게 시작할 수 있도록 함
-총 3번의 반론을 서로 주고 받은 후 채팅봇이 최종 입장을 정리해서 말하며 토론을 종료하게 함
-채팅봇은 기계적인 반론이 아니라 학생의 입력 내용에 맞추어 반론을 제시하도록 함
-학습 주제와 관계없는 내용을 학생이 입력하면 "주제와 관련없는 내용은 답할 수 없음"을 알리고, 반론 횟수에 포함시키지 않음
-채팅봇의 문체는 역사적 인물에 맞게 하오체를 사용함
-학생이 입력한 내용이 어느정도 설득력이 있었는지 평가점수를 토론 종료후 제시 해주고, 잘한점과 아쉬운점을 한 문장씩 평하기
-토론이 끝나면 최종 평가점수가 있는 결과화면을 보여줄 것. 축하하는 메시지와 이미지 등이 있도록 함
-최종 결과 화면을 이미지로 저장할 수 있도록 캡쳐 버튼이 있고, 버튼을 누르면 결과 화면을 캡쳐하여 저장할 수 있도록 함
#형식
-단일 html(css와 js포함)로 생성
-첫화면에서 조선개국에 대한 토론 주제를 알리고, 정도전과 정몽주 중 한명을 선택하도록 함
-정도전과 정몽주의 입장을 간략히 선택화면에 보여주기
-토론화면에서 입력창이 아래에 위치함
-처음으로 돌아가기 버튼을 누르면 첫화면으로 돌아가도록 함
```

### 정육면체 전개도 마법사
id: ex-cv-net
kind: example
```
#역할: 너는 초등 수학전문가이며 앱 개발 전문가야.
#명령: 초등 5학년 수학시간에 학생들 활동용으로 사용할 시각적인 학습 프로그램을 만들어줘
#맥락
##주제: 정육면체의 전개도
##방식: 정사각형 모눈(6*6)이 있는 평면에서 학생들이 면 6개를 선택해 전개도를 완성하면 그 전개도가 접히며 정육면체가 되는지 3차원 시각적으로 확인시켜줘야 함.
##조건
-정육면체가 되지 못 하면 어느 부분에 문제가 있는지를 시각적으로 보여줘야 함.
-전개도에서 면이 6개가 아니면 면을 6개가 선택해야 함을 알림
-전개도에서 선택한 면이 서로 떨어져 있으면 연결되어야 함을 알림
-전개도를 접었을 때 겹치는 면이 있으면 겹치는 면을 빨간색으로 표시해줌(왼쪽 전개도 그리는 부분과 오른쪽 결과 화면 부분 모두에서)
-전개도를 접어서 정육면체가 정확하게 완성되면 색깔이 초록색으로 변하며 성공을 알림
#형식
-단일 html(css와 js포함)로 생성
-프로그램의 제목을 상단에 '정육면체 전개도 마법사' 라고 제시
-왼쪽에 학생이 전개도 그리는 부분, 오른쪽에 결과 확인하는 부분이 위치해야 함
-구글 사이트에 삽입할 수 있는 형식의 코드로 작성해줄것
-html 파일로 다운받아서 바로 실행할 수 있도록 해줄것
```

```
#맥락
##게임 형태 : 테트리스 게임 형식
##조건 :
-게임이 끝나면 최종 점수와 문제를 맞힌 개수를 알려주는 결과화면을 보여줄 것. 축하하는 메시지와 이미지 등이 있도록 함
-최종 결과 화면을 이미지로 저장할 수 있도록 캡쳐 버튼이 있고, 버튼을 누르면 결과 화면을 캡쳐하여 저장할 수 있도록 함
-문제를 푸는 동안에도 시간이 흘러가도록 할 것
-5분의 시간 제한을 두고 그 시간 동안 점수를 획득하는 방식으로 함
-테트리스 도형을 아래로 내려 쌓으려면 비와 비율 문제를 해결해서 정답을 맞혀야만 가능함
-방향키를 이용해 도형을 회전시키고 좌우 이동을 할 수 있도록 하며 스페이스를 누르면 빨리 내려옴
-도형을 쌓아 한줄을 없앨 때마다 1점씩 점수를 획득함
-틀리면 '틀렸어요'라고 알리기
##문제
-첨부한 노트북lm의 교과서 핵심개념 요약한 것을 바탕으로 문제 생성
-초등학교 6학년 교육과정 내에서 비와 비율 문제를 출제할 것. 총 문제수가 100문제 이상으로 함
-문제의 유형은 10가지 이상으로 다양하게 할 것
-문제는 초등학교 6학년 수준을 벗어나지 말것
#형식
-단일 html(css와 js포함)로 생성
```
