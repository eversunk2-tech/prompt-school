### 복습 게임 웹페이지
id: cv-game
meta: 연수 실습④. '연소의 조건' 사례를 일반화한 판. 끌기와 누르기를 처음부터 함께 요구
check: PC와 태블릿(휴대폰)으로 각각 끝까지 해 보고, 안 되는 점을 본 그대로 알려 고치세요.
```
#역할: 너는 초등 [교과] 수업용 웹앱을 만드는 개발자이자 [학년] [교과] 교사야.
#명령: 첨부한 노트북의 '[단원명]' 지도서 내용만 근거로, 학생이 혼자 하는 '[게임 이름]' 웹페이지를 만들어 줘.
#맥락
##대상: [학년], [태블릿 세로 / PC] 화면
##구성: ① [핵심 개념 활동, 예: 조건 카드 3장을 모닥불로 옮기기] ② 오개념 OX 퀴즈 [N]문제 ③ 틀린 문제는 지도서의 [실험 결과/사례]로 설명
##조건: 지도서에 없는 내용은 넣지 말 것. 큰 글씨, 밝은 색, 효과음 없이. 점수와 '다시 하기' 버튼. 카드는 터치·마우스 모두 끌 수 있고(Pointer Events), 끌기가 어려운 학생을 위해 한 번 누르면 옮겨지게.
#형식: 단일 HTML 파일(Canvas에서 바로 실행)
```

### 소크라테스식 학습 튜터 웹앱
id: cv-socratic
meta: 2026 프롬프트 연수 원본(국회 튜터)을 노트북 근거·두 번 틀림 규칙으로 보강
```
#역할: 너는 [교과] 교육 전문가인 초등 수석교사이자 앱 개발자야.
#명령: [학년] 학생들의 [교과] 학습을 위한 학습 튜터 웹앱을 만들어 줘.
#맥락
##조건
- 주제: [차시]-[학습 주제]
- 학생의 질문에 답을 바로 알려 주지 말고, 힌트 질문을 계속 제시하며 스스로 답을 찾게 함(소크라테스식). 두 번 틀려도 정답 용어는 말하지 않음.
- 처음 시작할 때 튜터 소개와 함께 예시 질문 2~3개를 보여 줌.
##제한사항
- 첨부한 노트북의 내용만 근거로 답하고, [학년] 교과 수준을 벗어나지 말 것.
- [학년] 수준 어휘로 3~4문장 이내.
- 선정적·폭력적이거나 주제와 관계없는 대화에는 "그러한 대화는 할 수 없습니다. 학습에 집중하세요."를 붉은색으로 표시.
```
